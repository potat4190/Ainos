# Translations awaiting native review

Every UI string added while implementing `AINOS-SPEC.md` was translated by Claude Code and needs a native speaker's check before it can be called final (owner's decision, 2026-10-29). This file lists each one in one place: the key in `public/js/i18n.js`, the English text, and the current translation.

How to review: correct the translation in `public/js/i18n.js` (same key, same language), then tick the row here and add your name. A placeholder such as `{n}` must stay exactly as written.

Catalog display names in other languages (from `scripts/catalog-names.js`, Phase 1) are listed at the end, once chosen.
